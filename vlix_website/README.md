# Vlix Download Page

This is the official download page for the Vlix streaming app.

## Features
- Automatic device detection (Android, Windows, Mac, iOS).
- Direct download links for beta installers.
- OS-specific installation instructions.
- Slick, dark-mode design.

## Development
Open `index.html` in your browser to view the page.
To simulate different devices, use your browser's developer tools.
